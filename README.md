# Laws.Africa Developer Guide

Use the Laws.Africa Legal Knowledge Platform to build products grounded in
authoritative African legal information.

The platform has two main APIs:

* **Knowledge Bases** help you retrieve relevant legislation and judgment
  context for AI grounding, RAG, legal agents, search and workflow tools.
* **Content API** gives you full legislation collections, structured formats and
  metadata for deeper integrations inside your own systems.

Start with Knowledge Bases if you want the fastest path to a working
integration. Use the Content API when your product needs full local copies of
legislation, point-in-time versions, XML, HTML, PDF, lifecycle metadata or
webhooks.
